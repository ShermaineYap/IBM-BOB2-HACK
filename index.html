Why score at all

Most AI audit demos show a scan that finds everything. That proves nothing, because you can't tell what it missed. Seeding the target first turns "Bob found 8 issues" into "Bob found 8 of 10, with 1 false alarm" — a number a security lead can act on.

Matching rule: same file, same category, line within ±3. Each seeded defect can be matched once. Anything unmatched is a false positive.

Re-run: node scripts/score_audit.mjs

How Bob does it

Two project skills in .bob/skills/ tell Bob exactly what to do. Bob runs them in Agent mode, fans out one subagent per file, and writes files — not chat — that this page renders.
